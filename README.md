# 💇‍♀️ Lumm – Salon Booking & Management Application

**Lumm** is a salon booking and management application designed to simplify salon appointments, product purchases, and customer visit history.

The application provides a convenient platform where customers can schedule salon services, explore beauty products, manage upcoming appointments, and review previous visits.

## 📌 Project Overview

Lumm aims to improve the salon experience by introducing a digital solution for appointment scheduling and customer management.

The project is being developed using **HTML, CSS, JavaScript, and Android Studio**, with a focus on creating a user-friendly and responsive application.

## ✨ Key Features

### 📅 Salon Appointment Booking
- Browse available salon services.
- Select preferred appointment dates and times.
- Choose a stylist for the appointment.
- Schedule and manage salon bookings.
- Cancel upcoming appointments.

### 🛍️ Salon Product Store
- Browse available salon and beauty products.
- View product information and prices.
- Add products to a shopping cart.
- Update product quantities.
- View the total purchase amount.

### 🕒 Appointment History
- View upcoming salon appointments.
- Review previously scheduled appointments.
- Keep track of salon visits.

### 📱 User-Friendly Interface
- Clean and modern application design.
- Responsive layouts.
- Simple navigation.
- Easy appointment scheduling.

## 🚀 Getting Started

### Prerequisites

- Visual Studio Code or another code editor
- Modern web browser
- Git
- Android Studio (for Android development)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/lumm.git
```

**2. Navigate to the project directory**

```bash
cd lumm
```

**3. Run the web application**

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

### Android Development

Android Studio is used for the Android development workflow. The current HTML, CSS, and JavaScript implementation can serve as the frontend foundation for an Android application.

An Android project with a WebView or another suitable integration is required to run the web interface as an Android app.

## 💾 Data Storage

The current frontend version uses JavaScript `localStorage` to store application data, including:

- Salon appointments
- Booking history
- Shopping cart information

Data is stored locally in the user's browser.

A backend database will be required for synchronized customer accounts, shared salon schedules, and real product orders.
